# ResumeIQ - Frontend

This is the frontend for the ResumeIQ Career Intelligence Engine, built with React and Vite.

## Tech Stack
- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS 4
- **Icons**: Lucide React
- **Animations**: Framer Motion

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```

The frontend is configured to communicate with the backend API at `http://localhost:8000/api`. If the backend is offline, the app includes fallback mock data to gracefully demonstrate its features.

**For the full application architecture and flow, please see the [Root README](../README.md).**
